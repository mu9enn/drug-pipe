# MolClaw JSON contract patch

Target commit: `180abb7679ffc5b1ca9974e7390e141d8098f642`.

`molclaw-json-contract-v4.patch` changes only the three CSVs' output instructions
and adds a strict scoring entrypoint. Scientific questions, candidates, labels
and `eval_runner.py` mathematics remain unchanged. The contract module in the
patch is generated byte-for-byte from Drug-Pipe's shared implementation; edit
that implementation and rerun `build_patch.py`, never edit a second parser.

From a checkout of the pinned MolClaw commit:

```bash
git apply --check /path/to/molclaw-json-contract-v4.patch
git apply /path/to/molclaw-json-contract-v4.patch
python molbench/eval/score_json.py --suite ms1 --predictions finals.json --output results/ms1
```

The predictions file maps `molbench_ms1_001` etc. to raw final assistant strings.
Use a separate output directory per suite. Missing answers and invalid formats
produce empty predictions and remain in the 50/37/25 denominators. Transport
failure classification belongs to the agent runner; this offline entrypoint
reports missingness and format/constraint compliance, without declaring a run
publishable. Preserve the distinction between task accuracy and upstream
auxiliary metrics such as specificity.

The patch was applied to the immutable source snapshot, and all three entrypoints
were tested with entirely missing predictions. This artifact has not been
submitted or published upstream.
